## Features

- Visual agent builder with drag-and-drop roles, tools and communication links
- Parallel task orchestration with automatic delegation and result merging
- Support for local models and remote API providers through a unified connector
- Live execution graph showing every agent message, tool call and token cost
- Reusable workflow templates with export, import and scheduled runs
